# Anixart achievement manager
Консольная утилита для получения ачивок в аниксарт
# Использование
Создайте файл `token.txt`, введите туда свой токен и запустите программу
# Помощь
Если у вас есть айди других достижений, и вы хотите добавите его в эту программу - откройте issue или pull request.
